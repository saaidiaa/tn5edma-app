# 🎓 أكاديمية الثالثة أساسي — حلقات يوتيوب تعليمية

سلسلة حلقات أفقية **1920×1080** مستوحاة من البرنامج الرسمي للسنة الثالثة أساسي:
أرقام **لاتينية**، صور توضيحية **واقعية**، تعليق صوتي تعليمي مميّز، وملف ترجمة
SRT يتولّد أوتوماتيكياً مع كل حلقة.

صفحة العرض: `index.html` — كل فيديو معاه **عنوان احترافي** + **إعدادات نشر
يوتيوب** (النشر الأول) و **فيسبوك/ريلز** (النشر الثاني) مع أزرار نسخ.

## 🚀 التشغيل

```bash
pip install pillow arabic-reshaper python-bidi imageio-ffmpeg   # مرّة وحدة

cd t3
python3 render_t3.py --scenes lessons/ep4_multiplication.json \
        --out out/ep4_multiplication.mp4 --bgm      # --bgm = موسيقى خلفية هادئة

python3 make_thumbs.py     # صور مصغرة ليوتيوب (out/thumbs/)
python3 make_shorts.py     # نسخ Shorts عمودية 9:16 (out/shorts/)

# صفحة العرض
python3 -m http.server 8000     # ثم افتح /t3/index.html
```

### خيارات المحرّك
- `--bgm` موسيقى بيانو خافتة متولّدة بالكود (بلا حقوق) · `--bgm-vol 0.30`
- إذا `height > width` في JSON ➜ تخطيط عمودي أوتوماتيكي (Shorts)
- `"reveal_at": 0.62` في سطر ➜ يظهر بعد 62% من مدّة المشهد (لأسئلة الكويز)

## 📝 بنية ملف الحلقة (JSON)

```jsonc
{
  "title": "عنوان الحلقة",            // الشريط الأصفر العلوي
  "episode": "1",                      // شارة EP
  "brand": "أكاديمية الثالثة أساسي",   // التوقيع أسفل
  "width": 1920, "height": 1080, "fps": 24,
  "scenes": [
    {
      "audio": "audio/ep1_s1.mp3",     // مدة المشهد = مدة الصوت
      "image": "assets/img/....jpg",   // الصورة الواقعية (يمين)
      "caption": "فقاعة تحت الصورة",
      "board_title": "شارة اللوحة",
      "lines": [                        // أسطر اللوحة (تظهر تدريجياً)
        { "text": "54 872", "style": "eq" }
      ],
      "narration": "نص التعليق…",       // يولّد ملف SRT
      "confetti": true                  // لمشهد الخاتمة
    }
  ]
}
```

### أنماط الأسطر `style`
`eq` أسود كبير · `op` أحمر (العملية) · `ask` بنفسجي (السؤال) ·
`answer` أخضر + دائرة يدوية · `label` شارة صغيرة · `small` نص متوسط
