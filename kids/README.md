# 🦉 نونو البومة — مشروع فيديوهات تعليمية للأطفال

قناة فيديوهات عمودية (1080×1920) للأطفال من **3 إلى 7 سنوات**، بالعربية،
مع شخصية ثابتة **نونو البومة** وصوت معلّمة لطيف.
كلّ حلقة تتصنع من ملف JSON واحد — بلا مونتاج، بلا برامج ثقيلة.

**الحلقة 1 جاهزة:** `out/numbers_1_5.mp4` — الأعداد ١ ← ٥ (≈83 ثانية).

---

## 🚀 التشغيل

```bash
pip install pillow arabic-reshaper python-bidi imageio-ffmpeg   # مرّة وحدة

cd kids
python3 render_kids.py --scenes lessons/numbers_1_5.json --out out/numbers_1_5.mp4
python3 render_kids.py --scenes lessons/shapes.json --out out/shapes.mp4
python3 render_kids.py --no-audio                                # معاينة سريعة
```

## 🎬 أنواع المشاهد

| النوع | شنوّة يعمل | الحقول |
|---|---|---|
| `intro` | ترحيب + نصّ كبير نطّاط | `big` |
| `count` | رقم كبير + رسوم تُعدّ وحدة وحدة + رقم تحت كلّ وحدة | `digit`, `word`, `emoji`, `n` |
| `quiz` | سؤال ➜ الطفل يعدّ ➜ الجواب يظهر مع نجوم | `n`, `emoji`, `answer`, `reveal_at` |
| `letter` | حرف عربي عملاق + كلمة | `letter`, `word` |
| `shape` | شكل هندسي + اسمو | `shape` (circle/square/triangle/star), `word` |
| `outro` | تهنئة + كونفيتي | `big`, `confetti` |

**حقول مشتركة:** `audio` (مدّة المشهد = مدّة الصوت) · `owl` (`hello`/`ask`/`happy`) · `caption` (فقاعة الكلام)

### الرسوم المتوفّرة لـ `emoji`
`apple` 🍎 · `balloon` 🎈 · `star` ⭐ · `heart` ❤️ · `flower` 🌸
(كلّها **مرسومة بالكود** — موش صور، ما تتبكسلش، تكبر و تصغر بحرّية)

### الثيمات `theme`
`candy` (وردي دافي) · `meadow` (أخضر مرح) · `ocean` (أزرق هادي)

## 🎙 الصوت

الملفات في `audio/`. كل مشهد يقرا ملفّو والمحرّك يحسب المدّة أوتوماتيك
(+ `--tail` 0.7 ثانية تنفّس بعد كل مشهد).
تنجّم تسجّل بصوتك ولا تستعمل TTS عربي.

**نصيحة:** خلّي الصوت **بطيء وواضح**، وكرّر العدّ («واحد… إثنين… ثلاثة») —
الأطفال يتعلّموا بالتكرار.

---

## 👶 قواعد ذهبية لمحتوى الأطفال

1. **حركة دائمة** — نونو تهزّ، العناصر تنطّ. الطفل ما يملّش.
2. **عنصر واحد في كل مرّة** — ما تعرضش 5 حاجات دفعة وحدة.
3. **تفاعل:** اسأل «قدّاش من نجمة؟» واسكت ثانيتين — الطفل يجاوب بصوت عالي.
4. **مكافأة في الآخر:** كونفيتي + «برافو!» ➜ إحساس بالإنجاز.
5. **1 – 2 دقيقة** للفئة 3-5 سنين، حتّى 4 دقائق للـ 6-7 سنين.
6. **ألوان دافية وناعمة** — تجنّب الألوان الصارخة جداً والوميض السريع.
7. **سلسلة مرقّمة:** «الحلقة 1، 2، 3…» بنفس الشخصية ➜ الطفل يطلب الحلقة الجاية.
8. **YouTube Kids:** فعّل «مصنوع للأطفال» في الرفع، وتجنّب أي محتوى مخيف.
