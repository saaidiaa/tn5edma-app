# Tn5edma — تطبيق عروض الشغل التونسي 📱

تطبيق مجاني 100% يقرأ العروض مباشرة من مدونة **Tn5edma.com** ويعرضها مرتبة حسب الأقسام،
مصمم لسوق الشغل التونسي (مناظرات الوظيفة العمومية + عروض الشغل الخاصة + العمل بالخارج).

الموقع الحي: https://saaidiaa.github.io/tn5edma-app/

## ✅ ما تم إنجازه
- تطبيق ويب متجاوب (يعمل على الهاتف والكمبيوتر) بواجهة عربية RTL.
- قراءة مباشرة من المدونة عبر **JSONP** (بدون أي خادم أو تكلفة).
- الأقسام مرتبة تلقائياً حسب تصنيفات المدونة:
  - الوظيفة العمومية · عروض الشغل الخاصة · وزارة الداخلية · وزارة الدفاع الوطني
  - وزارات أخرى · العمل بالخارج · نتائج المناظرات
- بحث فوري + عدّاد العروض + استخراج "آخر أجل" تلقائياً + تنبيه انتهاء الآجال.
- زر **تثبيت التطبيق** على شاشة الهاتف (PWA) + العمل بدون إنترنت للواجهة.

### بوليش 2.1
- ⭐ **المفضلة:** زر ☆/★ على كل بطاقة وفي نافذة التفاصيل، وقسم «المفضلة» — محفوظ في `localStorage`.
- ⚠️ **إخفاء المنتهية:** يخفي العروض التي فات آخر أجلها ويعرض العدد المخفي.
- ⏰ **ترتيب:** الأحدث أولاً، أو الأقرب انتهاءً حسب آخر أجل.
- 💾 **حفظ الاختيارات:** القسم، البحث، إخفاء المنتهية، والترتيب تُستعاد عند إعادة الفتح.
- 📴 **كاش Offline:** عند فشل الاتصال تُعرض آخر عروض حُفظت على الجهاز.
- مشاركة تعمل عبر Web Share API مع نسخ الرابط كاحتياط.
- استخراج أجل محسّن: عربي بدون همزة (`اخر اجل`) وفرنسي (`date limite`, `janvier`…).

## 🤖 المجمّع التلقائي (المرحلة 3)
سكربت Node **بلا اعتماديات** (ESM) يكسح مصادر شغل تونسية موثوقة و يوحّدها في ملف
`data/jobs.json` واحد يقراه التطبيق مباشرة (نفس مخطط Blogger، + `source`/`sourceLabel`).

- **مصادر مفعّلة:** Tanitjobs · Keejob · بوابة المناظرات العمومية (concours.gov.tn) · Tanqeeb (مفلتر لتونس) · ANETI · وزارة الداخلية · وزارة الدفاع (best-effort).
- **مستثنى (محجوب / ToS):** LinkedIn (Cloudflare + login) و OptionCarriere (Cloudflare Turnstile) — نضيفوهم لاحقاً عبر API رسمي مدفوع.
- **الخصائص:** كل مصدر `adapter` معزول (فشل واحد ما يوقف الباقي)، احترام `robots.txt` + `Crawl-delay`، UA واضح فيه رابط تواصل، تأخير بين الطلبات، dedupe بالرابط و بالعنوان، كتابة `data/jobs.json` + commit تلقائي.
- **التشغيل:** `node scripts/aggregate.mjs` (محلياً)؛ أوتوماتيكياً كل 6 ساعات عبر `.github/workflows/aggregate.yml` (cron + تشغيل يدوي).

العروض المجمّعة تندمج مع عروض المدونة داخل التطبيق، و يظهر لكل عرض **شارة المصدر** لإضافة الموثوقية.

## 🚀 التشغيل محلياً
```
cd tn5edma-app
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`

## 📁 الملفات
- `index.html` — واجهة التطبيق
- `style.css` — التنسيقات
- `app.js` — منطق التطبيق (جلب البيانات، التصنيف، البحث، المفضلة)
- `manifest.webmanifest` + `sw.js` — إعدادات التطبيق القابل للتثبيت
- `icons/` — أيقونات التطبيق
- `index-single.html` — نسخة ملف واحد للنسخ الاحتياطي / التجربة السريعة
- `scripts/` — المجمّع التلقائي (lib + adapters لكل مصدر + `aggregate.mjs`)
- `data/jobs.json` — مخرجات المجمّع (يولّدها الـ workflow أوتوماتيكياً)
