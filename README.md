# Tn5edma — تطبيق عروض الشغل التونسي 📱

تطبيق مجاني 100% يقرأ العروض مباشرة من مدونة **Tn5edma.com** ويعرضها مرتبة حسب الأقسام،
مصمم لسوق الشغل التونسي (مناظرات الوظيفة العمومية + عروض الشغل الخاصة + العمل بالخارج).

## ✅ ما تم إنجازه (الخطوة 1)
- تطبيق ويب متجاوب (يعمل على الهاتف والكمبيوتر) بواجهة عربية RTL.
- قراءة مباشرة من المدونة عبر **JSONP** (بدون أي خادم أو تكلفة).
- الأقسام مرتبة تلقائياً حسب تصنيفات المدونة:
  - الوظيفة العمومية · عروض الشغل الخاصة · وزارة الداخلية · وزارة الدفاع الوطني
  - وزارات أخرى · العمل بالخارج · نتائج المناظرات
- بحث فوري + عدّاد العروض + استخراج "آخر أجل" تلقائياً + تنبيه انتهاء الآجال.
- زر **تثبيت التطبيق** على شاشة الهاتف (PWA) + العمل بدون إنترنت للواجهة.

## 🗺 خارطة الطريق (خطوة بخطوة)
| الخطوة | المهمة | الحالة |
|---|---|---|
| 1 | تطبيق يقرا من المدونة ويصنّف العروض | ✅ منجز |
| 2 | نشر التطبيق مجاناً (GitHub Pages / Cloudflare Pages) | ⏭ التالية |
| 3 | Workflow تلقائي (GitHub Actions) يجمع عروضاً من مواقع شغل تونسية (Tanitjobs, Keejob…) | ⏭ |
| 4 | ربط ثنائي: نشر تلقائي للعروض المجمّعة في المدونة (Blogger API) | ⏭ |
| 5 | إشعارات (فايسبوك / تيليغرام) عند صدور عرض جديد | ⏭ |

## 🚀 التشغيل محلياً
```
cd tn5edma-app
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`

## 📁 الملفات
- `index.html` — واجهة التطبيق
- `style.css` — التنسيقات
- `app.js` — منطق التطبيق (جلب البيانات، التصنيف، البحث)
- `manifest.webmanifest` + `sw.js` — إعدادات التطبيق القابل للتثبيت
- `icons/` — أيقونات التطبيق
