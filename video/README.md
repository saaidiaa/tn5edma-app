# 🎬 مولّد فيديوهات «المعادلات الرياضية بالكرتون»

نيتش: تاخو معادلة رياضية بسيطة ➜ تحوّلها لفيديو عمودي كرتوني (1080×1920) بشخصية
متحرّكة + تعليق صوتي عربي + خطوات الحل تظهر وحدة وحدة ➜ تنشرو على
Reels / TikTok / YouTube Shorts.

مثال جاهز: `out/video.mp4` (≈ 53 ثانية، حلّ `2x + 3 = 11`).

---

## 1) شنوّة يلزمك (مرّة وحدة)

```bash
pip install pillow arabic-reshaper python-bidi imageio-ffmpeg
```

`imageio-ffmpeg` يجيب ffmpeg وحدو — ما تحتاجش تنصّبو يدوياً.

## 2) التشغيل

```bash
cd video
python3 render.py                                  # يقرا scenes.json ➜ out/video.mp4
python3 render.py --scenes lessons/pythagore.json --out out/pythagore.mp4
python3 render.py --no-audio                       # معاينة سريعة بلا صوت
```

## 3) كيفاش تعمل درس جديد (دقيقتين)

انسخ `scenes.json` وبدّل المحتوى فقط:

```jsonc
{
  "title": "نظرية فيثاغور",        // العنوان الأصفر الفوقاني
  "brand": "Tn5edma · رياضيات",    // التوقيع التحتاني
  "width": 1080, "height": 1920, "fps": 30,
  "scenes": [
    {
      "audio": "audio/p1.mp3",      // التعليق الصوتي (مدّة المشهد = مدّة الصوت)
      "mascot": "think",            // think | explain | happy
      "caption": "شنوّة طول الوتر؟", // فقاعة الكلام
      "board_title": "المعطيات",     // الشارة الخضراء داخل اللوحة
      "lines": [
        { "text": "a = 3 , b = 4", "style": "eq" },
        { "text": "c = ?",         "style": "ask" }
      ]
    },
    {
      "audio": "audio/p2.mp3", "mascot": "happy", "caption": "الجواب!",
      "board_title": "النتيجة",
      "lines": [{ "text": "c = 5", "style": "answer" }],
      "confetti": true              // مطر كونفيتي في مشهد الخاتمة
    }
  ]
}
```

### أنماط الأسطر `style`
| النمط | اللون | الاستعمال |
|---|---|---|
| `eq` | أسود | المعادلة الأساسية |
| `op` | أحمر مرجاني | العملية اللي نعملوها (`- 3   - 3`) |
| `ask` | بنفسجي | السؤال (`x = ?`) |
| `answer` | أخضر + **دائرة مرسومة باليد** | الجواب النهائي |

> إذا مشهد ما عندوش `audio`، حط `"duration": 4.0` بالثواني.

## 4) الصوت

- الملفات في `audio/*.mp3`، كل مشهد يقرا ملفّو.
- تنجّم تسجّل بصوتك، ولا تستعمل TTS عربي (المثال متولّد بـ TTS بالدارجة التونسية).
- الأداة تحسب مدّة كل ملف أوتوماتيك وتخلّي المشهد يقعد قدّ الصوت + `--tail` (0.6 ثا).

## 5) الشخصية (Mascot)

`assets/mascot_explain.png` · `mascot_happy.png` · `mascot_think.png`
صور PNG بخلفية بيضاء — السكربت يشيل الخلفية أوتوماتيك.
تحبّ شخصية أخرى؟ بدّل الصور بنفس الأسماء (نفس الستايل باش تبقى متناسقة).

## 6) الوصفة اللي تخلّي الفيديو ينجح في هالنيتش

1. **هوك في أول 2 ثواني:** المعادلة تبان قبل أي كلام، والسؤال `x = ?` بارز.
2. **خطوة وحدة في كل مشهد** — ما تكدّسش 4 أسطر في لوحة وحدة.
3. **لون ثابت للمعنى:** أحمر = العملية، أخضر = الجواب. المتفرّج يتعوّد.
4. **10 – 60 ثانية** برشا. أقصر = إعادة مشاهدة أكثر = وصول أكثر.
5. **الجواب في الآخر + كونفيتي** — يخلّي المتفرّج يكمّل للنهاية.
6. **سلسلة:** نفس العنوان + نفس الشخصية + رقم الحلقة ➜ متابعين وفاء.
7. **CTA:** «حلّ هالمعادلة في الكومنتار 👇» في الوصف.

## 7) الإخراج

- MP4 · H.264 · 1080×1920 · 30fps · صوت AAC — مقبول مباشرة في
  Facebook Reels · Instagram · TikTok · YouTube Shorts.
- المدّة تتحسب أوتوماتيك من الصوت.

## 📁 الهيكلة

```
video/

├── scenes.json      ← سيناريو الدرس (المكان الوحيد اللي تحرّرو)
├── assets/          ← الشخصية + الخطوط
├── audio/           ← التعليقات الصوتية
└── out/video.mp4    ← الناتج
```
